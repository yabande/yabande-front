# How to set up

## Running the relay app

1. As in the process of development, make sure the realy app is up & running.

## Frontend

1. Create a `.env.development` file in the root of project.
2. Create and env varibale named `VIRE_RELAY_APP` and set it to point to the url
   of relay instance.
3. Open another terminal
4. `npm run dev`
